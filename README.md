CampusPlanner - 대학생 일정 및 과제 관리 시스템

1. 프로그램 소개

CampusPlanner는 대학생들이 수업 일정과 과제 일정을 효율적으로 관리할 수 있도록 만든 웹 프로그램입니다.

2. 주요 기능

* 일정 및 과제 추가
* 등록된 일정 전체 확인
* 날짜별 일정 관리
* 일정 저장 기능

3. 사용 방법

1. 웹사이트에 접속합니다.
2. 일정 추가 메뉴에서 일정 제목과 날짜를 입력합니다.
3. 등록된 일정을 확인할 수 있습니다.
4. 저장 기능을 이용하여 일정을 파일로 저장할 수 있습니다.

4. 개발 목적

대학생들이 학업과 과제 일정을 보다 편리하게 관리할 수 있도록 제작하였습니다.

5. 개발 도구

* HTML
* CSS
* JavaScript
* GitHub Pages
